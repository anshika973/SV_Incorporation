SV INCORPORATION — WEBSITE PACKAGE
==================================

Pages included
- index.html       Home page with the new four-slide hero carousel and Star Performer Brands section
- about.html       About page with Shravan Singh (Founder & Director) and Vijaylaxxmmi Singh (CEO)
- properties.html  Property categories and searchable filters
- investment.html  Investment guidance and enquiry links
- contact.html     Contact form, site-visit details and contact information

Assets
- assets/sv-logo.png: website logo from the original project
- assets/team/shravan-singh.jpg: supplied portrait of Shravan Singh
- assets/team/vijaylaxxmmi-singh.jpg: supplied portrait of Vijaylaxxmmi Singh
- assets/projects/: residential project visuals used across the website
- Star Performer Brands displays Paradise, Dream, Satyam, Today and Lodha in custom typographic wordmarks.

How to preview
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Keep an internet connection available for linked photography and Google Fonts used in existing parts of the site.

Interactions included
- Responsive shared navigation with About page added
- Four-slide homepage hero carousel with supplied founder photo, project visuals, manual controls, auto-advance and reduced-motion support
- Homepage property search forwarding to the property page
- Property search and location/type filters
- Save/favourite controls on property cards (current visit only)
- Contact/site-visit form that prepares an email in the visitor's default email app
- Newsletter form that prepares an email; it does not silently subscribe or store addresses
- Phone, email and WhatsApp contact links

Important notes
- No property prices are displayed.
- Project cards are visual showcases, not a live inventory. Confirm exact project names, configurations, availability and terms with SV Incorporation.
- The five Star Performer brand cards are custom text-based wordmarks, not official downloaded brand artwork. Replace them with approved official logo files if those are available to the company.
- This is a static HTML/CSS/JavaScript website. Contact submissions are not stored on a server; visitors review and send a prefilled email from their own email application.
